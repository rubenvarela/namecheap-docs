# 3. Download and installation

Installation of module is very simple and takes just a few minutes:

1. Download and extract attached archive. It can be downloaded [here](https://github.com/namecheap/ssl-whmcs). Copy the contents of the "ssl-whmcs-master" folder to the root folder of WHMCS (folder structure will remain the same).

2. Go to the WHMCS Admin area, select "Setup > Addon Modules" and activate the "Namecheap SSL Module Addon".

3. Next, click "Configure" next to the addon and check the "Full Administrator", "Sales Operator" and "Support Operator" boxes in the "Access Control" section that will appear. Then click "Save changes".

Installation is complete!

---

**Important**
**Note:** 

*If you receive any errors or cannot access addon**, please set up access permissions to addon for everyone as described above.*
