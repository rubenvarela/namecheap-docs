# Is there an API module available for WHMCS?

Namecheap API registrar module for WHMCS can be downloaded [here](https://github.com/namecheap/domains-whmcs).

Namecheap.com WHMCS registrar plug-in is an open-source plug-in that is distributed free of charge. It focuses on integrating Namecheap as a domain registrar at WHMCS.

We also have an SSL module for WHMCS. This module allows you to automate SSL Certificate sales with the Namecheap platform. Please [click here](https://www.namecheap.com/support/knowledgebase/category.aspx/2196/whmcs-module-for-ssl) for more information.

That's it!
