# 2. Sandbox and Production environments

Namecheap has a production as well as a test server environment. The test server environment is called Sandbox. We urge you to test the plug-in in our [sandbox environment](http://www.sandbox.namecheap.com/), before pointing it to production. It uses same calls as our production environment except that you will not receive actual SSL product in the end of the process and will not be charged real money. Difference between setting product for Sandbox and for production will be described in "Setting up products and pricings" section.
