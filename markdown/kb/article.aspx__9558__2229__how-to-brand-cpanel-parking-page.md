# How to brand cPanel parking page

     If you have a Reseller package with us, you can easily create branded parking page for the new clients.
Default parking or index page is the page that is displaying once domain is pointed to the new cPanel account.

The page can be as fancy as you would like, after all it is something you greet your new customers with!

 

To set it up, follow the steps below:

   **1.** Log in to your \*main cPanel account\* and go to **File Manager**
   **2.** Navigate to **/home/cPuser/cpanel3-skel/public\_html** folder

   **3.** Create a new file and name it *index.html*

   
**4.** Once the *index.html* page is created, you may open and develop it with built-in **HTML Editor**
 

 
If you wish to insert the [company logo](https://www.namecheap.com/logo-maker/company-logo-dos-donts/), you will need to upload the logo picture to **/home/cPuser/cpanel3-skel/public\_html** folder as well.

  

The **skeleton directory** allows you to easily replicate the files located in it into every new account’s *public\_html* and *public\_ftp* directories.

 
This is it!
Go ahead and create new cPanel account to verify the result.
