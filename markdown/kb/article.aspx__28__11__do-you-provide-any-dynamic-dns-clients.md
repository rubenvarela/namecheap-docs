# Do you provide any Dynamic DNS clients?

Yes, we do provide a free [Dynamic DNS](article.aspx__33__11__what-is-dynamic-dns.md) client called **Namecheap.com Dynamic DNS Client**. It supports only **Windows OS** at this time.

This software is not intended to replace any available advanced DNS clients and is merely provided for your convenience. You may use any dynamic DNS client of your choice that supports our system

Implementation details are given below.
Please note that we do not provide any support for third-party clients.

Until you find a suitable client, you can surely use one of the versions of our **Dynamic DNS Client**.

System requirements:

* **Dynamic DNS client V2.0**: Windows 2000/XP/Vista/7/8/10, Internet Explorer, Microsoft .NET 2.0 Runtime. For more details, on V2.0, you can refer to [Using Namecheap Dynamic DNS Client Version 2.0x (beta)](article.aspx__111__11__using-namecheap-dynamic-dns-client-version-20x-beta.md).

* **Dynamic DNS client V0.01**: Windows 2000/XP/Vista/7/8/10, Internet Explorer, Visual Basic Runtime. You can check detailed information for this version in [Using Dynamic DNS Client – Version 0.01](article.aspx__596__11__using-dynamic-dns-client-version-001.md). Most computers will have Visual basic runtime. If you have problems running the software, please download it from the [Microsoft website](https://www.microsoft.com/en-us/download/details.aspx?id=24417).
